- **方法**：对白皮书列出的每个数据源做真实 HTTP 探测，记录状态码与返回内容。下文所有"实测"均为本次真实输出。

## 一、结论：只需要注册 1 个账户

| 数据源 | 需要账户？ | 实测结果 | 备注 |
|---|---|---|---|
| **FRED（圣路易斯联储）** | ✅ **需要** | 无 key 请求返回 `{"error_code":400,"error_message":"Bad Request. Variable api_key is not set."}` | 免费，注册后申请 32 位小写字母数字 key |

> 注：下列命令中的 `abcdefghijklmnopqrstuvwxyz123456` 是 **FRED 官方文档页上的演示密钥**，非真实凭据，可安全留存。

```
$ curl -s "https://api.stlouisfed.org/fred/series?series_id=WALCL&file_type=json"
```

## 三、三个必须知道的问题

### 问题 1：白皮书写的「CBOE 官网 Daily Market Statistics CSV」目前走不通

实测结果：

```
403  https://cdn.cboe.com/data/us/options/market_statistics/daily/2026-10-14_daily_options_volume.csv
403  https://cdn.cboe.com/api/global/us/options/market_statistics/daily/2026-10-14_daily_options_volume.csv
404  https://www.cboe.com/us/options/market_statistics/daily/2026-10-14_daily_options_volume.csv
404  https://www.cboe.com/publish/scheduledtask/mktdata/datahouse/totalpc.csv   （旧版 CSV，已下线，返回 404 页面）
```

CBOE 官网已改为 Next.js 应用，数据服务端渲染进 HTML 的 RSC payload，**没有公开的 CSV/JSON 下载端点**（页面上的"Download CSV"按钮走的路径返回 403）。

**可用替代**：抓 `?dt=` 页面并从 HTML 中解析 PCR 字段。缺点：
- 不是稳定接口，CBOE 改版即失效；
- 需要解析而非直接读 CSV；
- 每取一天要多请求一次（历史回填成本高）。

**建议**：既然 PCR 是模型的核心输入，应把"解析器"和"数据获取"分成两层，解析器配一组**离线保存的样例页面**做回归，CBOE 一改版就能立刻发现。

### 问题 2：FRED 的 ICE BofA 信用利差只剩 3 年历史（硬约束）

`BAMLH0A0HYM2` 实测：**793 个数据点，范围 2023-10-16 → 2026-10-13**。

FRED 系列页原文：

> "Starting in April 2026, this series will only include 3 years of observations. For more data, go to the source."

**影响**：白皮书最缺的正是回测验证，而信用维度（权重 25%）的历史被砍到 3 年。跨 2020 年 3 月、2018 年 Q4 这类关键压力期的回测**无法用 FRED 完成**。

**可选出路**：
- 用代理变量重建长历史（如 HYG/LQD 价差、HYG 相对无风险利率的利差）；
- 向 ICE Data 购买长历史（付费）；
- 接受 3 年窗口，并在文档里显式声明回测边界。

### 问题 3：ICE BofA 数据「仅供内部使用」，禁止再分发

FRED 系列页原文：

> "The end of day Index values, Index returns, and Index statistics ("Top Level Data") are being provided for your **internal use only** and you are not authorized or permitted to publish, distribute or otherwise furnish Top Level Data to any third-party without prior written approval of ICE Data."
>
> "Copyright, 2023, ICE Data Indices. **Reproduction of this data in any form is prohibited** except with the prior written permission of ICE Data Indices."

**影响**：只要系统产出里包含 HY OAS 数值并对外分享（截图、看板、报告、公开仓库），就踩线。内部自用没问题。
